# HAPP Control

Go-приложение управляет процессом HAPP через HTTP API и перенаправляет TCP-соединения к его локальным прокси.

## Запуск

Требуются Go 1.22 или новее и Linux. Для подключения и работы с подписками нужен исполняемый файл `/usr/local/bin/happ`.

```bash
go build .
DATA_DIR=./data UI_LISTEN=127.0.0.1:8080 ./happ-control
```

По умолчанию данные хранятся в `/data`, а HTTP-сервер слушает `:8080`. Порт `11080` перенаправляется на SOCKS-прокси HAPP, порт `11081` — на его HTTP-прокси.

Проверить состояние можно запросом `GET /api/status`. Чтобы включить веб-интерфейс, поместите его собранные файлы в `web/dist/` с точкой входа `index.html` и повторите сборку. Пока этих файлов нет, запрос к `/` возвращает сообщение о недоступности интерфейса, а API работает.

## Проверка

```bash
go vet ./...
go test -race ./...
```

Тесты используют подставную команду HAPP и локальные TCP-соединения.
